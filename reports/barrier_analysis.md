# 障壁分析：この手法を Re s > 1/2（リーマン予想）まで延ばせるか

**結論**：延ばせない。論文の構成をそのまま一般化すると、到達できる境界には少なくとも三段階の下限がある。論文自身のパラメータ化（$M+\ell=1$）では、低評価の幾何だけで $\sigma_0\ge 2/3$、臨界線付近の自明に数えられる行によって $\sigma_0>13/15\approx0.8667$、現在の行数評価では $\sigma_0\approx0.8745$ が限界になる。7/8 はこのパラメータ化のほぼ最適値であり、ブートストラップを繰り返しても約 0.8745 に収束するだけである。リーマン予想（$\sigma_0=1/2$）の証明は、この手法の延長では原理的に得られない。

再現コード：`numerical_checks.py`（厳密算術）と、本ファイル末尾のモデル定義。図：`fig_barrier.png`。

## 1. 境界を決める式（厳密）

論文の低評価（命題 15.3）と主 Mellin 信号の正規化（式 `old-eq:5.11`）から、次が成り立つ。
$$C(s)=\frac{l_x}{2}+s-1+\frac h6,\qquad |J|\ll Z^{l_x/2+b/12+\epsilon}\quad\Longrightarrow\quad \sigma_0=1-\frac h6+\frac b{12}.$$
両段階で数値が一致することを確認した（`numerical_checks.py` の B1–B7）。

| | $h$ | $b$ | $\sigma_0$ |
|---|---|---|---|
| Part I | 1/2 | 0 | 11/12 |
| Part II | 13/16 | 1/8 | 7/8 |

- $1/6$ は、Poisson 周波数 $ua^6$ の $a$ 和が与える $\zeta_F(6z)$ の極 $z=1/6$ に由来する。これは六次（立方テータ由来）構造そのものである。
- $h=1-l_x+\ell$ は Poisson 行のノルム高さを表す。$\sigma_0=1/2$ を得るには $h\ge3$ が必要になる。
- 論文の正規化 $M+\ell=1$（$M=l_x+l_y$。両段階で成立）を課すと、$\sigma_0=\tfrac23+\tfrac{l_x}{2}+\tfrac b4\ge\tfrac23$ となる。

**障壁 A（低評価の幾何）**：$M+\ell=1$ の下では、どの幾何を選んでも $\sigma_0\ge2/3$ である。この正規化を外すには、プローブの長さ・素スロット・完備行の規模の関係を作り直す必要がある。論文が使う十分条件 $l_x-\ell\ge3/16$（再スケールした尺度 $X/q_{p_J}\ge Z^{3/16}$ を保つ条件）の下では $h\le13/16$ となり、Part II の選択はこの上限に一致している。

## 2. 高評価：零点検出器と行数

論文の一般式（`lem:bin-contour-accounting`、式 `eq:stage-high-exponent`）は
$$E_{\sigma_0}(d;R,g)=a-\sigma_0+h(z_0-\tfrac16)-a\,l_y-\tfrac\ell2+g+d\,(R+\tfrac\delta2-z_0),\qquad z_0=\tfrac{17}{50},\ \delta=2a-1$$
である。各行ビン（零点の実部 $\le a$）の寄与は $Z^{C(\sigma_0)+E}$ となり、矛盾には（$\Delta\to0$ の極限で）すべてのビンで $E<0$ が必要になる。

**障壁 B（臨界線付近の行）**：$\delta\to0$、すなわち零点の実部が 1/2 に近い行を考える。$L$ 関数の零点はほぼすべて臨界線の任意の近傍にある（Bohr–Landau／密度評価）。各行は高さ $T$ までに $\asymp T\log(qT)$ 個の零点を持つので、行数の節約はあり得ず $R(0)=1$ となる。$d=h$、$q=0$、$R=1$ を代入し $\sigma_0=1-h/6+b/12$ と $M+\ell=1$ を使うと
$$E=1-\tfrac52 l_x-\tfrac{13}{12}b<0\iff \tfrac52l_x+\tfrac{13}{12}b>1 ,$$
となり、したがって $\sigma_0=\tfrac23+\tfrac{l_x}{2}+\tfrac b4>\tfrac23+\tfrac15=\tfrac{13}{15}\approx0.8667$ が従う。

- これは行数評価をどれほど改良しても越えられない。**密度仮説並みの行数** $R=1-\delta$（すべての $\delta$）を仮定して最適化しても、最小値は $13/15$ のまま変わらない（数値最適化で確認：$l_x=2/5,\ b=0$）。
- 検出器の床 $a=51/100$（$\delta_0=1/50$）を含めると、床だけで $\sigma_0\ge 0.86979$ となる。

これは密度評価と零点非存在領域の関係として古典的に知られる障壁の、この手法における具体形である。$\sigma\to1/2$ では「零点を持つ行」と「持たない行」が区別できないので、節約が消える。

## 3. 現在の行数評価での最適値と、ブートストラップの反復

§20 の明示的な不等式（適応域 $\mathcal J,t,R_*$、端点 $\delta=\alpha$、床、中間域 $d\le1/2$、小ノルム行、素数供給 $\ell/h>7/37$）を、幾何 $(l_x,b)$ の関数としてそのまま再構成した。論文の値で再計算すると、余裕は論文と完全に一致した（適応域の最小余裕 $2.28\times10^{-4}$、床 $7/1200$、中間域 $49/14400$、小ノルム行 $63/800$、供給 $23/1443$）。このモデルで $\sigma_0$ を最小化した結果は次の通り。

| 事前上界 $\alpha=2\beta_*-1$ | 最小の $\sigma_0$ | 最適幾何 $(l_x,b,\ell,h)$ | 効いている制約 |
|---|---|---|---|
| 5/6（Part I の 11/12 から） | **0.87496** | (0.3545, 0.1241, 0.1668, 0.8123) | 適応域（零点検出行の数え上げ） |
| 3/4（7/8 を入力に再適用） | **0.87451** | (0.3718, 0.0877, 0.1686, 0.7968) | 適応域 |
| 反復の固定点 | **≈0.8745** | — | — |

論文の幾何に課された十分条件 L1・L2 を外しても結果は変わらない。

- 7/8 は、このパラメータ化の最適値 0.87496 から $4\times10^{-5}$ しか離れていない。論文は余裕を残して切りの良い値を選んでいる。
- 7/8 を入力にしてもう一段ブートストラップしても、改善は約 $5\times10^{-4}$ にとどまる（`improvement_exploration.md`）。

## 4. 論文中の補題が明示的に 7/8 で止まっている箇所

| 箇所 | 仮定 |
|---|---|
| `lem:bin-contour-accounting`（共通の周回積分補題） | $\sigma_0\in[7/8,1)$ |
| `lem:local-euler` 第二領域（主行補正の正則性） | $\Re x\ge7/8,\ \Re z\ge33/200,\ \Re w\ge19/20$ |
| `lem:plain`（短い素因子付き四次モーメント） | $3/4\le\kappa\le1$、すなわち $\beta_*\ge7/8$ |
| 行数の容量 $z_P=(1-2m)/(6\kappa)$ | $D_x,P_x$ は $\kappa=3/4+2\Delta$（$\Delta\to0$）で導出されていると推定される |

$\sigma_0<7/8$ を狙うには、これらの補題を範囲外まで再証明する必要がある。§3 のモデルはそれらが**同じ式のまま延長できると仮定した楽観的な見積もり**である。

## 5. リーマン予想に関する結論

1. **低評価の構造**：$\sigma_0=1-h/6+b/12$。$\sigma_0=1/2$ には $h\ge3$、すなわちプローブ長 $Z$ をはるかに超える $Z^3$ 規模の Poisson 行が必要になる。論文の正規化（$M+\ell=1$）の下ではこれは起こり得ず、$\sigma_0\ge2/3$ である。
2. **密度障壁**：$\sigma_0\to1/2$ の極限では、すべての行が臨界線付近に零点を持つ。検出器に基づく行の節約が消えるため、論文の正規化では行数をどれだけ改良しても $\sigma_0>13/15$ にとどまる。
3. **ブートストラップの飽和**：$\beta_*$ の事前上界を改良して反復しても、約 0.8745 に収束する。
4. **質的な障壁**：$\sigma_0=1/2$ の矛盾には、プローブ全体が $Z^{C(1/2)}$ 以下、すなわち主信号（Möbius 型の和）と同程度の平方根相殺を示す必要がある。大篩と Cauchy–Schwarz による平均二乗評価は一般の係数に対して最良であり、それを超える相殺は事実上 RH 級の情報を要する。

したがって、**「同様の手法でリーマン予想を証明する」ことはできない**。これは計算資源や努力の不足によるものではなく、手法の構造に由来する。$\sigma_0$ を実質的に下げるには、少なくとも (i) 六次構造 $ua^6$ とは異なる周波数構造を持つ別の保型核、(ii) 臨界線近傍の行を自明に数えずに済む機構、の両方が必要である。これは新しいアイデアの領域であり、本検証の範囲を超える。

## 付録：モデルの定義（Python）

```python
z0=17/50; dmin=1/100
def model(lx,b,alpha):            # M+ell=1 normalisation (both stages satisfy it)
    ell=1-2*lx-b; h=2-3*lx-b; ly=lx+b; s0=2/3+lx/2+b/4      # s0 = 1-h/6+b/12
    E=lambda d,dl,R,q: (1+dl)/2-s0+h*(z0-1/6)-(1+dl)/2*ly-ell/2+q*ell+d*(R+dl/2-z0)
    # adaptive range: R_* from Prop 19.2 / Lemma 20.2 with D_x=3-17x/9, P_x=(2-8x/9)(1-x)
    # endpoint delta=alpha: R=1-delta; floor delta0=1/50: R=1; intermediate d=1/2: R=76/75-2delta/3
    # small rows: h(z0-1/6)-ly/2+2dmin<0; supply ell/h>7/37
```
前提：補題 17.1・18.1・19.2 の行数式と、局所 Euler 領域・周回積分の位置（$z_0=17/50$、床 51/100）を固定している。これらの補題が延長できない場合、実際の限界はさらに悪くなる。
